Activa el panel de administración

El panel necesita una base de datos gratuita en Supabase para guardar fotos, solicitudes y textos con seguridad. Es un paso de una sola vez (unos 15 minutos):

  1. Crea un proyecto gratis en supabase.com.
  2. En SQL Editor pega y ejecuta el archivo supabase.sql del proyecto.
  3. En Authentication › Users › Add user crea la cuenta de la administradora (marca Auto Confirm User) y vuelve a ejecutar la última parte de supabase.sql.
  4. En Project Settings › API copia la Project URL y la clave anon public.
  5. En GitHub: Settings › Secrets and variables › Actions › Variables crea SUPABASE_URL y SUPABASE_ANON_KEY con esos valores y vuelve a publicar.

La guía completa, paso a paso, está en el archivo GUIA_DESPLIEGUE.md.
